1. App name, problem, and who it serves

App name

BridgeTalk

What it does

BridgeTalk helps young adults prepare respectful, bilingual (English and Urdu) conversations about important life decisions. You describe who you will talk to and what you need to explain. The app returns a structured conversation pack: a calm opener, clear wording, the other person’s likely worries, safer phrasing, and a practical next step.

Real problem it solves

In many families (especially South Asian and Pakistani households), hard talks about freelancing, gap years, changing degrees, moving cities, or personal timelines become emotional quickly. People often know what they want, but freeze on how to say it with respect. BridgeTalk is not a “convince your parents” tool. It is a communication coach that improves clarity and empathy. It never promises agreement.

Who it is for

Students and young adults preparing talks with parents, siblings, relatives, partners, mentors, or teachers.

4. AI feature

What the AI does

The core AI feature is conversation pack generation. The user submits situation details, the API calls the generation pipeline, the model returns JSON only, Zod validates the shape, Roman Urdu is converted to proper Urdu script when needed, and the pack is shown on the result page.

Provider order

  1. Google Gemini (primary)
  2. OpenAI (optional fallback)
  3. Built in demo pack (always available)

System prompt (authored for this project)

Stored in src/lib/prompts/system.ts. Core instructions:

  • Act as a calm communication coach for young adults.
  • Help both sides understand each other.
  • Improve communication. Never promise agreement.
  • Never make the other person the villain.
  • Never coach manipulation, guilt, or “winning”.
  • Stay culturally aware without stereotyping.
  • Use simple spoken wording.
  • English: natural and respectful.
  • Urdu: proper Arabic / Nastaliq script only. Never Roman Urdu.
  • Fit wording to audience.
  • Return valid JSON only for the conversation pack fields.

7. How to run the project

Requirements

  • Node.js 20+ recommended
  • npm
  • Optional Google Gemini API key for live AI generation

Local setup

  1. Clone the public repository.
  2. Run npm install.
  3. Copy .env.example to .env.local.
  4. Add GEMINI_API_KEY (optional but recommended).
  5. Run npm run dev.
  6. Open http://localhost:3000

Notes for graders

  1. Create an account (local to the browser), then open Prepare Conversation or Skills.
  2. If no AI key is configured, generation still works using the demo pack.
  3. With a Gemini key on Vercel, the live site generates real packs.
  4. Confirm the repository is public in an incognito window.
  5. Never commit .env.local.

Privacy and academic honesty note

BridgeTalk was designed and built as an original student project around a real communication problem. Conversation packs and skills data stay in the browser. Local sign up or sign in is device based for product flow. Production AI keys must stay in host environment variables only.
